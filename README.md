# 청각장애 | 언어재활사 2급 국가시험 대비 2D 강의

[바로 재생하기](https://leenk1808-dotcom.github.io/hearing-disability-exam-animation/)

귀의 구조와 소리 전달, 청각검사와 청력도 해석, 보장구와 의사소통 지원, 청각장애의 언어발달 영향, 청능훈련을 다루는 한국어 장면형 강의야.

## 재생 기능

- 10개 음성 강의 장면과 장면 바로가기
- 재생, 일시정지, 탐색, 재생 속도 조절
- 무음 기출 연결 퀴즈 9문항
- 별도 파일이나 외부 오디오 서버 없이 `index.html` 하나로 재생

## 참고

- 언어재활사 2급 국가시험 학습용으로 제작
- 음성: ElevenLabs
- 음성 및 화면은 개인 학습 목적의 교육 자료
